How to Use

The createLinearGraph() function accepts a JSON configuration object with the following structure:

{ "segments": [ { "x_start": number, // Starting x coordinate "x_end": number, // Ending x coordinate "y_start": number, // Starting y coordinate "y_end": number, // Ending y coordinate "segment_color": string // Color (name, hex, rgb, etc.) } ], "width": number, // Optional: Canvas width (default: 800) "height": number, // Optional: Canvas height (default: 600) "padding": number // Optional: Padding around graph (default: 50) }

The function automatically scales the segments to fit the canvas and adds coordinate axes for reference.
